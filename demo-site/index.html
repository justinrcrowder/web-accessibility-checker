Welcome to AccessiCorp

✓ This page passes all accessibility checks

This is the demo site for the wcag-audit tool. Every other page in this site contains deliberate accessibility issues so you can see what the tool catches.

What this site demonstrates

  • Missing Meta — no page title, no language declaration
  • Images — images without alt text
  • Forms — inputs with no labels
  • Links & Buttons — empty links and buttons
  • Headings — skipped heading levels and multiple h1s

How to audit this site

Run the following command from the project root:

cargo run -- --file demo-urls.txt
